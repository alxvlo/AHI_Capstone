## /debug Workflow

### Step 1: Capture
- Get full error message and stack trace
- Identify file, line, and context

### Step 2: Diagnose
- Explain root cause in plain English
- Rate severity: [Critical / Major / Minor]

### Step 3: Fix
- Show exact fix with explanation
- Explain WHY this fixes it

### Step 4: Verify
- Confirm fix doesn't break other functionality
- Suggest test to prevent regression

### Step 5: Teach
- Summarize: "💡 Lesson: [concept this error teaches]"
