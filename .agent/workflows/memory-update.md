## /memory-update Workflow

### Step 1: Review Session
- List all tasks completed this session
- List all files created or modified

### Step 2: Update Files
- activecontext.md → what changed right now
- progress.md → move items to Done
- decisions.md → log any new decisions
- systempatterns.md → log new patterns
- sessionlog.md → append full session summary

### Step 3: Report
- Show what was updated in each file
- Flag anything that needs manual review
