## /plan Workflow

### Step 1: Read Memory Bank
- Read projectbrief.md, techstack.md, activecontext.md
- State understanding of current project state

### Step 2: Clarify the Task
- Ask: What is the exact goal?
- Ask: What files/modules does this touch?
- Ask: What does "done" look like?

### Step 3: Generate Plan
- Task name and complexity rating
- Numbered steps with file impact
- Risk assessment
- Estimated scope

### Step 4: Confirm
- Present plan and ask: "Proceed or modify?"
